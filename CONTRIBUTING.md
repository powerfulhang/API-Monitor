# Contributing

Thanks for helping improve API Monitor.

## Development

Use Bun for local development:

```bash
bun install
bun test
bun run lint
bun run build
```

## Scope

This repository is an API-monitoring-focused fork of `ccstatusline`. Please keep changes aligned with that purpose:

- Claude Code status line rendering
- API credit and usage visibility
- compact terminal-safe display
- cross-platform Windows/macOS/Linux behavior

## Attribution

Retain upstream attribution for `ccstatusline` and clearly describe fork-specific changes in `CHANGELOG.md` or pull request notes.
